# 레벨 값 출처 등급

레벨 값 하나하나에 그 값이 어떤 근거에서 왔는지를 1~4 숫자 등급으로 붙인다. 라이브와
로컬 작업본 모두 등급 숫자만 저장한다. 등급은 출처 이름이 아니라 **근거의 종류**로
정하며, 값을 수집해 기록하는 시점에 정한다.

| 등급 | 뜻 | 예 |
|---|---|---|
| 1 | 제조사 공식 | 술을 만든 곳이 직접 밝힌 값: 기술 자료(잔당 g/L·산도), 라벨, 사케 사양(일본주도·산도), 법정 당도 표기(Brut, Sec 등) |
| 2 | 외부 평가 | 제조사가 아닌 곳이 그 술 하나를 평가한 값: 국가 판매처의 맛 시계, 매체·판매처의 단계 표시(와인21·데일리샷·술담화), 수입사·판매처·평론가의 소개 글이나 시음 글을 읽어 단계로 바꾼 값 |
| 3 | 사용자 평가 모음 | 우리 사용자 답변, 외부 리뷰를 여럿 모은 값. 몇 건부터 3등급으로 볼지는 사용자 답변이 쌓이기 시작할 때 정한다 |
| 4 | 종류 추정 | 그 술의 값이 아닌 것: 종류·스타일 평균, 같은 라인의 다른 제품, 도수로 짐작한 값 |

- 값이 여럿이면 높은 등급(작은 숫자)이 이긴다.
- 2등급 출처끼리는 순위를 두지 않는다. 값이 여럿이면 언제나 가운데 값(중앙값, 두 값이면
  평균을 반올림)을 쓰고, 차이가 커도 칸을 비우지 않는다.
- 2등급 값에는 값을 낸 출처 수와 가장 낮은 값·가장 높은 값의 차이를 함께 남긴다. 이
  기록은 카드에 쓰지 않고, 추천에서 비슷한 후보의 순서를 정하거나 다시 수집할 술을 고를
  때만 쓴다.
- 단어 하나만 보고 정한 값(예: 글에 '산미'가 있다 → 산미 4)은 근거로 보지 않고 저장하지
  않는다.
- 블로그와 개인 후기 한 건은 2등급 근거로 쓰지 않는다. 여럿을 모은 경우에만 3등급이 된다.
- 1·2등급 값은 근거 원문(문장 또는 표시된 숫자)과 URL을 함께 남긴다.
- 카드와 추천은 1~3등급을 "이 술은 ~해요"로, 4등급을 "이런 종류는 보통 ~해요"로
  말한다.
